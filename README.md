# Portfolio

Black & red developer portfolio built with React, Tailwind CSS, and Vite.

## Setup

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Customize

- Replace the name, copy, and project entries in `src/components/`.
- Swap the email in `src/components/Contact.jsx`.
- Colors and fonts are defined as design tokens in `tailwind.config.js`
  (`ink`, `surface`, `line`, `bone`, `smoke`, `blood`, `blood-dim`) —
  change them there and they update everywhere.
